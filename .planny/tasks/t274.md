Part of t272. Add `planny boards`, the one command the operator asked for:
it starts a board for every plan on this machine, serves the page that
links to them, and prints one address.

## Behaviour

- `planny boards` finds every plan under the home directory (or under each
  `--root <dir>` given), starts a board for each plan that has none, with
  the same detached start `planny serve --detach` uses, and leaves a
  running board alone. Then it runs the boards page in the foreground on
  port 5890 (or `--port`) and prints its address. `--detach` runs the page
  as its own detached process instead, like `serve --detach`.
- The page lists every plan by name and path, with a link to its board. A
  plan whose board is not running says so and names the command that
  starts it. The page finds the boards again on every load, so it is never
  stale.
- `planny boards --stop` stops the page and every board of every plan it
  finds.
- A board started this way runs whichever planny binary ran `planny
  boards`. To run one plan's board from another build (planny's own dev
  checkout, for example), stop that board in its directory and start it
  from that build; the page follows.

## Design constraints

- No new machinery for a board's lifecycle: the record, the probe, the
  detached start and the stop each plan already has are what this command
  loops over. The page's own detached start and stop share the same code
  as `serve`'s, extracted rather than copied.
- Port 5890 sits below the range `serve` scans from (5891 up), so the page
  and a board never collide.
- The page is server-rendered HTML with no script: a list of links.

Found on the first real run: the page walked the home directory on every
request, which takes over a second here, so the detached start's
one-second probe never saw it answer. The page now walks once at start and
again after a request once the last walk is 30 seconds old; a request only
probes the boards, so it answers in under half a second with three plans.
A new plan shows on a later load. That rule has its own test.
