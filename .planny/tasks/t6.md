The CLI keeps the store consistent, but hand edits can break it: dangling parent or blocked_by ids, duplicate priority ranks, parent or dependency cycles, cancelled tasks with active children. `planny doctor` should list each problem with the file path and suggest the fix; `--fix` applies the safe ones (drop dangling ids, re-rank duplicates).
