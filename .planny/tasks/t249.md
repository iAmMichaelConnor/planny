Built, 2026-09-02. The activity section listed two lines — "created by X" with
no time at all, and "started by X at <raw ISO stamp>". Every other action a
task records was missing.

The section now lists the task's whole recorded life: the creation, then every
history entry — status changes, priority moves, re-parents, dependency edits
and renames — oldest first, one per line, each with its actor where the store
has one and each with a time. The time reads as "31 Aug, 12:00" and carries
the exact stamp in a tooltip and in a <time datetime> attribute. Task ids
inside a line link like every other id on the board. The list scrolls past
about eight lines rather than pushing the rest of the drawer down.

Note for whoever touches this next: the board has no build step and cannot
import the CLI's renderer, so describeHistory now exists twice — src/render.ts
for the terminal and web/app.js for the board. They differ in one word by
design: the board says "status → done" because the time comes last there,
while the CLI prints the time first and a bare arrow reads fine.
