The core half of the parked status (parent t247).

Why: the claudebox store carries tasks whose names end in (PARKED) and whose
bodies hold a wake condition (t83, t84, t85, t86 under 'Parked coverage work');
'planny next' still serves them, so an agent picking from the top of 'next'
must read each body to learn it is not actionable.

Design: 'parked' joins STATUSES and ACTIVE_STATUSES. Parked work keeps its
priority rank, still blocks whatever waits on it, and still counts as not-done
in progress — only the queues pass it over. An optional wake note lives in a
new frontmatter field, parked_until.

Done looks like:
- 'planny park <id> [--until "<note>"]' parks a task; 'planny todo <id>' wakes
  it and clears the note.
- 'planny next' and 'planny decisions' skip parked tasks; '--include-parked'
  brings them back.
- 'planny deps' skips them by default too.
- 'planny list --status parked' finds them, and 'planny show' prints the note.
- Tests: test/ops.test.ts, test/query.test.ts, test/cli.test.ts, test/render.test.ts.


Built, 2026-09-02. 'parked' joins STATUSES and ACTIVE_STATUSES, so parked work
keeps its priority rank, still blocks whatever waits on it, and still counts as
not done in progress. Only the queues pass it over.

One deviation from the plan above, with the reason: 'planny deps' still shows
parked tasks. That view draws chains, and hiding a node in the middle of a chain
breaks the chain it exists to explain. It already shows done and cancelled tasks
for the same reason. The '[~~]' mark labels a parked node in place.

New: 'planny park <id> [--until "<note>"]'; '--include-parked' on 'next' and
'decisions'; 'parked until:' in 'planny show'; the '[~~]' mark in the tree and
export; a 'stray-wake-note' doctor finding, fixable, for a wake note left on a
task that is not parked; and the board's status route accepts the note.

Refactor: one applyStatus helper now logs the status, sets it, and rewrites the
wake note. Every status change (set, cancel, resolve) goes through it, so a
stale reason never outlives the park it describes.
