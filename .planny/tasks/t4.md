Publish planny to npm through the GitHub Actions workflow. Two runs
failed on 2026-08-31; the setup is now correct and the remaining
blocker is on npm's side. Current state:

**Already done — do not redo:**

- The `NPM_TOKEN` repository secret is set and works. The first run
  failed with a 403 because the npm account requires 2FA for publishes
  and the first token lacked the bypass setting; the regenerated token
  fixed that. (If a token must ever be made again: on the granular
  access token form, tick "Bypass two-factor authentication" — it is
  off by default, and CI cannot answer an interactive 2FA prompt.)
- The workflow itself is correct. Tests, build, and the provenance
  signature all pass on every run.

**The remaining blocker — a 409 from the registry:**

The second run failed at the final upload with
`409 Conflict - Failed to save packument`. The name is not fresh: a
different npm user (`quentinodelavega`) published an unrelated
`planny@0.0.1` (an Angular 16 web app, per the npmmirror.com copy of
the record) on 2025-05-25 and it was unpublished on 2025-10-09. The
name is free to claim — unpublish was long over 24 hours ago — but
the leftover tombstone record makes the registry reject the packument
save. This 409 is usually transient. Note: the live registry's
tombstone now lists this project's operator as maintainer only
because the failed attempt on 2026-08-31 wrote that; it is not
historical.

**Next steps — retry with spacing:**

1. Re-run the workflow: repo → Actions → **Publish to npm** →
   **Run workflow** on `main`. A green tick = published. A failed
   attempt is harmless; nothing partial goes live.
2. If it 409s again, wait about an hour and retry once more.
3. Still 409: try once the next day, then contact npm support
   (https://www.npmjs.com/support) — explain that the name was
   unpublished by its previous owner in October 2025 and new
   publishes hit `409 Failed to save packument` on the leftover
   record. Renaming the package is the fallback if support stalls;
   that would be a new decision task (README, skill, and docs all say
   `planny`).

**After the first green run:**

1. Verify from any machine: `npm install -g planny && planny --help`,
   and https://www.npmjs.com/package/planny exists.
2. On npmjs.com, open the package → **Settings** → **Trusted

   `iAmMichaelConnor/planny`, workflow `publish.yml`. Save.
3. Delete the `NPM_TOKEN` secret on GitHub (repo → Settings → Secrets
