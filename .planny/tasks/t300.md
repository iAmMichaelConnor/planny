If a decision task is added and it doesn't have any titles which match the recommended layout, give a warning back to the ai so that it knows. Don't block the action or require interactivity. The return message is sufficient for ai to rethink and edit the message, I would think.

Consequences: ops warns, and never blocks, when an open decision body has no Background, no Proposal (or Options, or No proposal yet) and no Needed from you. The check runs on add, on a body write and on a conversion to a decision; a bump or a re-parent says nothing. Answered and cancelled decisions are left alone. A heading counts as a markdown heading or a bold line.
