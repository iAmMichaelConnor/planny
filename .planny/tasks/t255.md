Why: the board can only be driven with a mouse. The only keys that do
anything are Enter in the search box, Enter in the add-task notice, and
Cmd/Ctrl+Enter to save the drawer. Escape closes the search panel but not the
drawer, and the search results cannot be picked with the arrow keys — the
operator must reach for the mouse in the middle of a keyboard action.

Done looks like:
- Escape closes the drawer, then the search panel, in that order.
- "/" focuses the search box from anywhere outside a text field.
- Up and down arrows move through the search results, and Enter opens the
  highlighted one.
- Up and down arrows move between cards in the board and rows in the tree,
  and Enter opens the highlighted task in the drawer.
- A "?" key opens a short list of these keys.
- Every shortcut stays inert while the focus sits in a text box.

Files: web/app.js, web/style.css (a focus ring for the highlighted card),
test/ui.test.ts.
