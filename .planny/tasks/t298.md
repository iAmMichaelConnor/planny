If someone is typing in a box (description or decision response, or any input field), then if they click off the right pane that they've been typing in, have a "are you sure? " popup so that they don't accidentally lose their work

Consequences: leaving the panel with unsaved words asks 'Discard what you typed in the panel? It is not saved yet.' — on opening another task, closing the panel, Escape, a search hit, an id link, and starting a new task. Every way in and out now goes through one openTask/closeDrawer funnel, so the question lives in one place. A typed decision answer counts as unsaved work; it never arms Save by design. Files: web/app.js (drawerHasUnsaved, leaveDrawer, openTask, closeDrawer), test/ui.test.ts ('nothing typed is thrown away without a question'), README.md.
