## Background

The CLI works today via `npm link` from this checkout. Publishing to the
npm registry would let any machine run `npm install -g` without the
checkout. The registry name `planny-wanny` is free (checked 2026-08-31);
the name `planny` was unpublished by its former owner in 2025, and npm
restricts re-publishing recently unpublished names.

## Why this comes to you (the operator)

Publishing is public, permanent (unpublish is restricted), and happens
under your npm account. The package name is a product choice.

## Proposal

Stay on `npm link` until the tool has run one real project end to end, then
publish as `planny-wanny`.

*Pros:* the store format can still change freely while it is private (see
the storage ratification decision); publishing after real use ships a
sturdier v0.1.
*Cons:* until then, every machine needs this checkout.

## Needed from you

"wait" (default), or "publish now" plus the name to use.

## When

No cost until you want planny on a second machine or in CI.
