The operator does not want npm credentials on this box, and a machine admin could read anything stored here regardless. Publish from CI instead: an AI agent scaffolds .github/workflows/publish.yml (manual trigger, npm ci + test + build + npm publish --provenance); the operator adds NPM_TOKEN as a GitHub repository secret from their own browser — GitHub stores it, this machine never sees it. Prefer a granular token scoped to the one package with an expiry; after the first published version, switch the package to npm trusted publishing (OIDC from the workflow) and delete the token entirely.
