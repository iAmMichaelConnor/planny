When an agent (or the operator) creates, starts, finishes, cancels, reopens or resolves a task, the task records who: a session id or label. The CLI takes a global --session <id> flag, falling back to the PLANNY_SESSION environment variable; add stamps created_by, and every status change appends a history entry {at, status, by} (this builds the log t14 describes). UI mutations attribute to 'operator'. Getter output includes the attribution.
