Built, 2026-09-02.

The board: a Parked column sits before To do and appears only once the store
has a parked task, the rule the Cancelled column already follows. A parked
card keeps its priority number and its "▲ top" button, because a parked task
keeps its rank; it also carries a "wake" button. Parked is amber
(--st-parked), distinct from todo, in progress, done and cancelled in every
view, and it joins the status filter chips in the tree and the dependency
legend. The tree and the dependency view show parked work by default: it is
open work, not history.

The decisions tab: "Skip for now" is now "Park for now" and writes the parked
status, so the choice survives a reload and every reader sees it. The
client-side skip set is gone. The "Skipped for now" list became a "Parked
(still open)" list that shows each wake note and a "bring back" button.

The drawer: a park button joins the status buttons, and a "parked until" line
shows the note (or says none was recorded).

One shared helper, parkTask, asks for the note and posts it, so the drawer,
the cards and the decisions tab park the same way. Cancel abandons the park;
an empty answer parks with no note.

One defect fixed on the way: the board's activeTasks() hardcoded todo and
in-progress. After the core change the server counted parked tasks in the
priority order and the board did not, so every "#3 of 12" would have
disagreed with the store. There is now one isActiveStatus() helper mirroring
ACTIVE_STATUSES in src/types.ts, used by all six places that tested the pair.

Files: web/app.js, web/style.css, README.md (command table),
skills/planny/SKILL.md (action map row and the status reference).
Tests: test/ui.test.ts (12 new; three skip tests rewritten for parking).
How to test: npm test (510 pass). Runs at: the board, planny serve.
