Gap found in the 2026-09-01 skill review. Since 0.2.x any planny command can print the stderr warning 'the store looks older than what this machine last wrote — a git checkout or restore may have rewound the plan; restore it, or delete .planny/last-seen.json if the rewind was deliberate'. The skill says nothing about it, so a helpful agent's likely move is to delete the sidecar to silence the alarm — destroying the evidence and accepting the rewind on the operator's behalf. Add one bullet to the store-consistency rules: treat the warning as stop-the-line; report it to the operator and add an operator task or decision; never delete last-seen.json yourself — accepting a rewind is the operator's call.
