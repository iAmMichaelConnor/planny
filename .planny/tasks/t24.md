Any edit through the CLI (or another agent) shows up in an open UI without a manual reload. The server watches .planny/tasks and pushes a server-sent event (GET /api/events, debounced) on any file change; the page listens with EventSource and re-fetches state. Refreshes must not clobber typing: a drawer with unsaved edits keeps its form untouched, and decision response drafts survive a re-render with focus restored.
