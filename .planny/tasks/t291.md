Reported by the operator on 2026-09-02: "If I'm typing something into the UI, it seems that if I leave it a little while, it will disappear, maybe because of some refreshing or usage of planny via the CLI by some AI."

Text typed into the board and then left for a moment is lost. The board refreshes from the server on its event stream, on window focus, and after any change an agent makes through the CLI, and a refresh that rebuilds a view throws away whatever was typed into it.

Done looks like: text typed anywhere on the board survives every background refresh, including one caused by another writer changing the store. Nothing the reader typed is ever discarded without them asking.

Files: web/app.js. Run `npm test`.
