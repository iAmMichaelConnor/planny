Part of t272. A remote operator reaches a board through an SSH port
forward. The skill and the README give one forward for one board:
`ssh -L 5891:127.0.0.1:5891 <host>`. With a board per plan plus the boards
page, that becomes several `-L` flags typed by hand.

## Behaviour

`planny boards --forward` prints, on one line, the `-L` flags for the
boards page and for every board that is running: for example
`-L 5890:127.0.0.1:5890 -L 5891:127.0.0.1:5891 -L 5892:127.0.0.1:5892`.
Only the operator knows their host, so the command prints the flags, not
the whole ssh line: `ssh $(planny boards --forward) <host>` is the one
paste.
