I'm getting tired of juggling multiple ports for different planny sessions. Would it be possible to have a serve all option, which deterministically finds .planny plans on the user's machine (but not ones that exist within worktrees) and host them all? The ui would enable the name of the project (currently in the top-left) to be clickable to select which project the user wants to look at. We'd still completely silo the tasks of each plan (we wouldn't show a combination of tasks from different projects, for example). Each project would basically be viewed the same as we do today, just selectable under a drop-down by clicking the currently-showing project's name in the top-left.
