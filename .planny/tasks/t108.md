planny@0.1.0 is published, so the package settings page now exists and the one-time credential can be retired. Three steps, all in the browser, about two minutes total. 1: On npmjs.com, open the planny package, then Settings, then Trusted Publisher. Select GitHub Actions, repository iAmMichaelConnor/planny, workflow publish.yml. Save. 2: Delete the NPM_TOKEN repository secret on GitHub (repo Settings, Secrets and variables, Actions). 3: On npmjs.com Access Tokens, revoke the planny-publish token. After this, publishes keep working through OIDC and no credential is stored anywhere. Done when all three are removed or saved and a later workflow run still publishes.
