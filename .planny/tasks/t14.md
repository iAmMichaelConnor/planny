created and updated say when a task last changed, but not what changed. Append a history entry to the frontmatter on every status change — history: [{at, from, to}] — written only by ops. Then add `planny list --changed-since <time>` so an AI can catch up on all movement, not just decisions. One line per entry; no free-form text in history.
