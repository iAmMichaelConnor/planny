If i open a task in the rhs of the ui, it seems i can type alterations to its text box. It's not clear to me whether those result in changes to the raw file or not, or whether they _should_ even result in changes to the raw file. If a task is in progress already or done or cancelled, surely not.

Answer: typing in the drawer changes nothing until you press Save — fields are a local draft, and background refreshes deliberately leave a dirty form alone. Save issues one PATCH through the same ops codepath as the CLI, which writes the file. Saving IS allowed for done and cancelled tasks, on purpose: enriching a finished decision's outcome (what was built, where, how to test) is a core workflow. What was missing was feedback, now added: Save sits disabled until you type, so an untouched drawer visibly cannot write.
