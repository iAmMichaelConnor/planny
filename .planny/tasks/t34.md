Its honest scope is what pull cannot do: (a) harness-side wake-ups — emit NDJSON change batches so a hook can start or nudge a dormant agent when the operator acts; (b) a narrow interrupt filter (--only <ids>) for invalidation of work in flight (current task cancelled or changed, a blocking decision answered). Reuse the file watcher serve owns (factor out of src/server.ts). Events carry actors so consumers skip their own PLANNY_SESSION. The browser UI stays on SSE. Low priority: build when a real dormant-harness or invalidation use case shows up.
