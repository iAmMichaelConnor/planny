Operator request. A command that returns the link at which the localhost UI is currently hosted. Design: serve records its port in a store-level file when it starts listening (a sibling of cursors.json in the list of non-task files owned outside ops; document that in CLAUDE.md). planny url reads it, probes the port to confirm the server is alive, and prints http://127.0.0.1:<port>. No server or a stale record: a clear message and exit code 1. Red-green-refactor as always.

Built: startServer records {port, pid, started} in .planny/serve.json and removes it on close; servedStoreRoot moved from cli.ts into server.ts (one probe codepath); currentServeUrl probes the record and confirms the root before trusting it. planny url prints the address or exits 1 with run-planny-serve guidance. Tests: seven new cases across server.test.ts and cli.test.ts (record written and removed, live url, never-served, stale record, corrupt record, foreign server on the port, CLI happy and sad paths); 312 pass. Docs: CLAUDE.md store-file inventory, README command table, and the skill's serve-the-board check now uses planny url. Verified live against the dogfood board.
